# Parth Mahajan portfolio

## Direction
The supplied resume is the primary content source. Build a single-page, responsive portfolio in the existing repository, with technical work first and a complementary creative practice. Use the supplied dark/amber references, Marcus Lorenzet's oversized type and persistent navigation, and Pamidor's interdisciplinary project storytelling. No copied site assets or invented portrait.

Palette: ink #121211, charcoal #1c1c1a, ivory #f1eee8, muted stone #aaa8a1, copper #ff854d, warm line #34332f. Manrope variable type throughout. Large, lowercase name, a slowly moving metallic knot, quiet supporting copy and floating navigation. Typography and the copper-lit sculpture make the hero memorable; project media carries the rest of the experience.

Sections: introduction; NextStep AI and SentinelD; LOOPPOP and ORVEN creative concepts; biography and capabilities; experience/leadership; contact. Native accessible dialogs provide project context and video playback. Links to verified GitHub projects, LinkedIn, email and the original resume work without a backend. No pretend contact submission.

Build a local reviewable result. Publication is a separate action. No paid assets or AI generation needed. Respect reduced motion, keyboard navigation, mobile layout and focus visibility. The 3D scene must be progressive enhancement, with a CSS fallback.
